# S045 preregistered plan

Prepare a new native incremental counterexample-guided search on exactly 50
labelled vertices with two edge-disjoint planar layers and direct tests for
non-nine-colourability. No independence, symmetry, degree or exact-density
restriction. All 1225 pairs optional in either layer; disjointness enforced.
Native planarity cuts retain independent Kuratowski subdivision guards.
Every nine-colouring partition c justifies the clause requiring at least one
union edge inside a class of c. These clauses exclude only nine-colourable
graphs. Reuse one live native solver across candidate/colour feedback to
retain private learning. All external geometric and colouring rules durable.

Prerequisites: full fresh 271+K9 cloud_smoke.py on the Windows pinned tools,
portable S044 integrity replay, fresh native build, exhaustive five-vertex
fixed-layer controls, K3,3 rejection, retained positive split padded to 50,
incremental protocol and malformed-colouring controls, independent rotation
checks and chromatic SAT/UNSAT proof round trips. No scientific run before
smoke PASS. Existing Python/PySAT/NetworkX/compiler installations are reused
if accepted; install only missing dependencies.

Benchmark (registered before runs): three serial 60-second arms on the same
unrestricted 50-vertex domain: exact-candidate blocking; colouring-partition
cuts with default phases; colouring-partition cuts with positive edge phases.
All arms independently verify each returned planar pair and colouring.
Operational gate: at least one full candidate/colour feedback cycle, verified
cut replay, clean cooperative stop and successful semantic restart. Choose
the partition-cut arm with most verified candidates/second among passing
arms; tie favours default phases. Counts measure activity, not graph coverage
or probability of a witness. No mathematical performance gain presumed.
If a configuration fails, retain its failure and repair/retest before launch.

Initial sustained run: one generator plus a serial colouring oracle (generator
idle during oracle work), eight-hour wall ceiling from production launch,
600-second semantic checkpoint slices. One 3 GiB aggregate private-memory
hard limit for this run's process tree, 1.5 GiB available RAM floor, 10 GiB free
disk floor. No use of historical process controls. Slice boundaries retire
private CDCL and restart from independently audited semantic rules; no claim
of a private-state checkpoint. Resource floor breach stops rather than loops.
The new WMI launch is independent of the desktop app job; exact PID/create
time, append-only journals and atomic status identify this run. Cooperative
STOP file; watchdog acts only on this run's children and records any failure.
No automatic successor session, no recurring automation.

Stop on owner STOP, witness alert, bare native UNSAT (UNKNOWN pending standalone
proof), failed validation, dependency/source change, unsafe resource state,
eight-hour ceiling, or operational fault. Save graph/colour/embedding records
before feedback. Check every persisted colouring clause and native geometric
cut before semantic reuse. SAT colourings independently checked; a non-nine
alert needs standalone DRAT, both independently checked planar rotations and
a checked ten-colouring before claiming chi=10. Search timeouts remain UNKNOWN.

Successful launch is engineering acceptance, not a lower-bound advance.
Prior S11, order-3 and non-Ore UNKNOWN statuses remain. Prior-art admission
and corrected Hajós scope retained; no novelty claim. Register build, source,
input and checker hashes and environment receipts in validation/S045.
