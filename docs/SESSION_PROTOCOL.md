# One-session, proof-first protocol

## Entry
0. Cloud environment (D043): confirm the SessionStart hook completed (or run `bash scripts/cloud_setup.sh`), then run `.venv/bin/python scripts/cloud_smoke.py` before any scientific computation and record its verdict and `artifacts/tmp/native/ENVIRONMENT.json` hashes. Reset the harness-assigned session branch to live main. See docs/CLOUD_ENVIRONMENT.md.
1. Independently pin live main commit and tree, reconciled authored commits/PRs/merges, all recent/open PRs, branches and competing session records.
2. Enumerate workflow files, actual runs/jobs/check-runs/status contexts and reachable rulesets/protection; a missing hosted check never counts as a pass.
3. Read authority and full most-recent CLOSEOUT plus source/claim indexes, mathematical results, route failures and registered campaigns.
4. Preregister the exact session ID, owner instruction, nontrivial goals, candidate proofs, attempted counterexamples, computational limits and stop criteria. If owner prompt is outside tool reach, quote only faithful description, never fabricate its bytes.
5. One independent owner invocation permits one numbered session. Allow multiple ambitious attempts inside that session; stop before next session.

## Mathematics
- Distinguish maximum chromatic number χ₂ from minimum number of colours in one example and from geometric thickness.
- For constructions, both planar layers, edge disjointness, colouring ≤k and impossibility of k−1 colours are four distinct obligations.
- Upper-bound and universal colouring work is out of scope (D042). Structural lemmas are admissible only when used to prune or guide constructions, and must still survive adversarial checks.
- Full-bounded exhaustive computations need finite universe, canonical ordering, justified symmetry, exact reproducible code, independent checker and independently checked SAT certificate when used.
- Preserve failed strategies, explicit counterexamples and provenance. Keep inherited and source-stated mathematics separate from original results.

## Exit
- Update one consistent state, the paired source/claim ledgers, session/phase/decision/failure/campaign logs; record tested commands, exact outcomes, admitted limitations.
- Write sessions/S###/INPUT.md, PLAN.md, RESEARCH.md, ADVERSARIAL.md, CLOSEOUT.md and next FUTURE prompt.
- Include the cloud environment record and smoke-test result in the session manifest.
- One authored commit on isolated branch, PR and non-force merge wherever available. Independently inspect commit parent/tree/PR and observed post-merge main.
- Publication, Palomar and outreach are separately owner-gated.
