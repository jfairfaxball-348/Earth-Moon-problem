# GitHub integration evidence per session

- [ ] Capture live main SHA and tree, not a historical incoming SHA labelled outgoing.
- [ ] Enumerate all open/recent PRs and competing numbered branches/files.
- [ ] Inspect actual workflows/runs/jobs/status checks/rulesets; absence ≠ CI success; permission errors ≠ absence.
- [ ] Read AGENTS, state, protocol, catalogues and current head session.
- [ ] One isolated branch and one authored atomic commit; inspect actual commit tree and parent.
- [ ] PR created on actual branch head; no forced push, squash or rebase when two-parent merge is available.
- [ ] Independently verify PR merged and main contains actual two-parent merge (or explain GitHub exception).
- [ ] Verify synchronized state, sources/claims, phase/decision/failure/session ledgers.
- [ ] Prepare complete next FUTURE/UNEXECUTED prompt, not automatic permission to run.
- [ ] Record *verified* CI results separately from local checks.
