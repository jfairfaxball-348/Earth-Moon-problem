# Independent C5 containment CNF

This is a second exact algorithm for the four frozen S026 candidates, independent
of S025's count-vector backtracking. It is a source/certificate audit, not an
expanded candidate campaign. Register at most4x26=104 cases after the local queue,
one worker,11GiB; per-case45s external cap,20000 PySAT conflicts, native solve10s
and drat-trim20s for an UNSAT result. A cap/missing proof is UNKNOWN. Only checked
explicit maps transfer certified non-biplanarity to a candidate.

For each17-vertex obstruction H and target B[w], Boolean X[v,b] assigns v to a
target bag b. Exactly one bag per v is enforced by a positive row and pairwise
negative pairs. For each target bag b, every set of w[b]+1 vertices is forbidden
from all using b. For each H edge vz and each distinct nonadjacent pair a,b of B,
forbid X[v,a] and X[z,b]. These are direct literal clauses, without a cardinality
encoder or auxiliary variables.

Given a satisfying assignment, allocate distinct consecutive target labels within
each bag. Capacity guarantees injectivity. Every H edge maps either inside a
clique bag or between adjacent base vertices, so it is a target edge. The decoder
independently checks every mapped edge and injectivity on the explicit graph.

Conversely, any injective subgraph embedding induces those bag assignments and
satisfies all clauses. Permute vertices within each clique bag of H (true twins)
to make its assigned target-bag indices nondecreasing. This preserves every H
edge and makes the added ordering clauses hold. Thus the ordered formula is SAT
iff H embeds as a non-induced subgraph. It cannot reject a valid embedding merely
because the target has extra edges.

The H edge list generated from the weighted cycle must equal the actual certified
obstruction edge list before use. A DRAT proof establishes only this formula's
UNSAT; the equivalence above is the separate mathematical justification. Every
CNF is stored or regenerated byte-identically, and every negative accepted by the
audit needs native DRAT verification. This does not prove an Earth–Moon bound.
