# S022 — labelled exact-neighbourhood search: scope and mathematical proof

## Source, target, and proof scope

Graph148 is the original fixed S003/S004 exact-χ=10 source, not a newly constructed graph: 25 vertices, 131 original labelled edges, source edgefile SHA256 `4f8dab6cb2f936ba0c69613decab88f578e4692926baa09b4d387289cefae598`. S021 archived the disjoint planar partial sets A (62 edges), B (63 edges), and U (six unplaced edges), with A ∪ B ∪ U = E(G). Each full layer must have 62–69 edges if planar, from Euler's bound 3n−6=69, but this is a necessary, not sufficient, condition.

**Exact local-completeness lemma (elementary and non-novel).** Put P=A ∪ B. For any full edge partition E(G)=X ⊔ Y, define its switch set F=(A ∩ Y)∪(B ∩ X), and define a bit for each of the six U edges recording whether it belongs to X or Y. Then (F, six bits) determines (X,Y) uniquely; conversely every such tuple defines exactly one full partition. Thus the family with exactly r already placed baseline edges switched has cardinality `C(125,r)*2^6`, before planarity pruning. Enumerating all `C(125,r)` subsets of P, and all 2^6 assignments of U, without quotienting by layer swap or graph symmetry, is an *exact complete enumeration of this restricted Hamming layer-assignment neighbourhood*.

**Sound branch pruning.** For a fixed F, place its switched P edges on the opposite side and hold all other P placements fixed. If either partial layer is nonplanar, no addition of U edges can repair it, since every subgraph of a planar graph is planar. Otherwise, recursively assign the six edges of U in a fixed order to X or Y, rejecting a branch only when an intermediate partial layer is nonplanar. Every fully planar completion of this exact F is visited by this tree. The algorithm uses no visited-state set, no unjustified cost-dominance, no ejection search budget, and no non-existential symmetry cut. Finished radii r are therefore exhaustive *as labelled finite neighbourhoods*, subject to the reported full run and verified implementation. A time-capped radius is explicitly incomplete, and even exhaustion of all r≤3 does **not** prove global original nonbiplanarity: unexamined switch sets may need r≥4. Nor does S018's triangulation-cover equation q+r=7 restrict this switch radius.
