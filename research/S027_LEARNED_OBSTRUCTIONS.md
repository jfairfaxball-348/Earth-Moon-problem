# S027 learned obstruction-support clauses (CLM-0102)

Used only to prune candidate generation and to state finite profile-domain
results. Depends on certified non-biplanarity of each obstruction (S025/S026
native DRAT certificates, themselves resting on K9 thickness three, SRC-0014).
No novelty is claimed; see sessions/S027/PRIOR_ART.md (Patil, Trivedi, rStation).

## Setting
A profile is a fixed labelled weight vector w on base vertices 0..n-1 with
sum 28. A base graph B gives the clique blow-up B[w]: bag b is a clique of w_b
labelled vertices, and bags a,b are completely joined iff ab is a base edge.
An obstruction is a certified non-biplanar clique blow-up H = A[u].

## Support lemma
Let f: V(H) -> {0..n-1} assign each H vertex a target bag with |f^{-1}(b)| <= w_b,
such that for every H edge vz either f(v)=f(z) or f(v)f(z) lies in a set S of base
pairs. Then for every base graph B' with S contained in E(B'), H is isomorphic to a
(not necessarily induced) subgraph of B'[w], hence B'[w] is not biplanar.

Proof. Label the vertices of f^{-1}(b) by distinct vertices of bag b (possible by
capacity); this is injective. An H edge with both ends in bag b maps to a clique
edge of bag b. An H edge vz with f(v)=a != b=f(z) has ab in S, a subset of E(B'), so
the two bags are completely joined in B'[w] and the image is an edge. Thus H is a
subgraph. Subgraphs of biplanar graphs are biplanar (restrict both layers), so
B'[w] is not biplanar. QED.

Consequently the generator clause  OR_{e in S} NOT y_e  (y_e = "base edge e
present") removes only non-biplanar members of the profile domain. It forbids the
CONJUNCTION of the support edges, not a single labelled model, and is sound for
the fixed capacities w only.

## Transfer and symmetry
* Capacity transfer: an S026 map recorded for profile w_old (same base order)
  yields the same f; it is valid for a new profile w whenever the bag usage of f
  is at most w_b in each bag. The audited condition is exactly the lemma's
  hypothesis, re-checked on the support alone.
* Relabelling: if pi permutes base vertices with w_{pi(v)} = w_v, then
  pi induces an isomorphism B[w] -> pi(B)[w]. Hence the image clause on pi(S) is
  also sound. Up to 32 seeded random such pi are applied per learned clause.

## Euler subset clauses
For a set T of whole bags, the blow-up induced on T has
sum_{v in T} C(w_v,2) + sum_{ab in E(B), a,b in T} w_a w_b edges. A biplanar graph
on N>=3 vertices has at most 2(3N-6)=6N-12 edges, and induced subgraphs of
biplanar graphs are biplanar. If a chosen set of base edges inside T already
pushes the count above 6w(T)-12, every superset does too, so the conjunction is
forbidden. (Whole-bag unions suffice for this hereditary density test when all
bags have size <= 8 — the "blob unions suffice" lemma of rStation paper 36,
SRC-0042; S027 uses only the one-directional soundness, not that lemma.)

## Containment encodings
In-loop: one incremental SAT instance per (profile, obstruction) with base-edge
variables y and assignment variables X[v,b]; each generated model is tested under
assumptions. SAT models are decoded and explicitly checked twice (on the model's
edges and on the support alone). Audit form (admitted graphs): the S026
literal-clause CNF with fixed nonedge clauses (capacity by direct subsets when
C(|H|, w_b+1) <= 20000, otherwise a sequential counter), native CaDiCaL plus
drat-trim, and separately S025 count-vector backtracking.
Twin ordering inside each obstruction bag is safe because bag vertices of a
clique blow-up are closed twins.

## Profile-domain statements
If the generator formula of a profile (base constraints + learned clauses + any
blocking clauses) is UNSAT with a native DRAT proof, every learned clause is
independently justified (tools/s027_check_learned.py, which imports neither the
generator nor the encoder) and the CNF is regenerated byte-identically, and the
profile has no blocking clause, then: no base graph with alpha(B[w])<=3,
omega(B[w])<=8 and at most 156 blow-up edges gives a biplanar B[w]. K9-freeness
and the edge bound are necessary for biplanarity, so the profile contains no
biplanar clique blow-up with alpha<=3 (the members that would carry the counting
certificate chi>=10). Members with alpha>=4 are outside the domain and not
addressed. These are finite statements about fixed labelled profiles only.
