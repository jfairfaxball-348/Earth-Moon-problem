# Paper59 version3 supplement

Python3 standard library only. No network, credential, solver or external
path is required. All files are original CC0-1.0 code/data (LICENSE.txt).

The regular/ directory is essential evidence for the new abstract regular
packing theorem. Run python3 regular/verify_rup.py with assertions enabled;
read regular/README.md and SCHEMA.md for scope and the exact expected counts.

The three root verify_*.py files and their retained JSON results are unchanged
optional arithmetic controls from version2. Run each with python3. They print
PASS and rewrite their respective result JSON. The manuscript supplies the
coverage and topology arguments that these controls illustrate.

SHA256SUMS.txt records all supplied files except itself. The final regular
packet contains literal clauses, not a reference to a private proof archive.
